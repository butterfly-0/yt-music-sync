# YT Music Sync — Автоматичний завантажувач музики для Android

Автономний нативний додаток для Android (Kotlin + Jetpack Compose), який автоматично відстежує вподобані треки та обрані плейлисти на YouTube/YouTube Music, завантажує їх у найвищій якості безпосередньо у сховище смартфона (системну папку «Music») з вшиванням обкладинок високої роздільної здатності та повних ID3/M4A тегів.

---

## Основні можливості

- **Автоматична фонова синхронізація**: Робота у фоні за допомогою Android `WorkManager` (перевірка за розкладом: щогодини, кожні 2 години або раз на добу).
- **Енергоефективність та контроль трафіку**: Опції завантаження виключно при підключенні до **Wi-Fi** та/або **під час заряджання**.
- **Режим «Тільки нові вподобані»**: Можливість завантажувати лише ті треки, які були додані після першого запуску додатку, або виконати повну синхронізацію.
- **Вшивання HD-обкладинок та тегів**: Автоматичне завантаження обкладинки високої якості та вшивання метаданих (Назва, Виконавець, Альбом) у MP3/M4A файли.
- **Інтеграція з медіатекою Android**: Усі завантажені композиції реєструються в системному `MediaStore` (`Music/YouTubeSync/`) і миттєво з'являються у будь-якому плеєрі (Poweramp, Musicolet, Spotify Local Files, Samsung Music тощо).
- **Вбудоване прев'ю**: Можливість прослухати завантажений трек прямо в додатку (ExoPlayer).
- **Безпечна авторизація**: Вхід через Google WebView для доступу до приватного списку вподобаного без потреби налаштовувати сторонні хмарні API.
- **Дизайн**: Глибока OLED Dark тема з Material 3, розгорнутими картками треків та плавними анімаціями.

## Як зібрати та запустити проект

1. **Відкрийте проект в Android Studio**:
   - Оберіть `File -> Open` і вкажіть папку проекту `e:\idea`.
   - Дочекайтеся завершення Gradle Sync.

2. **Збірка APK**:
   - Через термінал:
     ```bash
     ./gradlew assembleDebug
     ```
   - Або в Android Studio: `Build -> Build Bundle(s) / APK(s) -> Build APK(s)`.
   - Зібраний APK файл знаходитиметься за шляхом:
     `app/build/outputs/apk/debug/app-debug.apk`.

3. **Встановлення на телефон**:
   - Підключіть Android-смартфон через USB (з увімкненим Debugging) або скопіюйте файл `.apk` на пристрій та встановіть його.
